# Grabación de pruebas de rendimiento

Nuestro equipo repitió las cargas de 100 y 300 usuarios sobre la copia local de eShopOnWeb. Grabamos directamente la ventana de Apache JMeter, sin micrófono, música ni audio del sistema. La ejecución y los contadores se ven a velocidad real.

Esta demostración usa la interfaz gráfica para mostrar la actividad. Sus mediciones se conservan por separado: el informe original corresponde a las ejecuciones CLI anteriores. La grabación no reemplaza esas mediciones.

Mostramos el plan, la solicitud HTTP local, el inicio de las cargas, el Summary Report en vivo y la revisión de respuestas y aserciones. Listar productos conserva la espera de 1000 ms del proyecto; no modificamos la aplicación para ocultar ese fallo.

El video final une dos grabaciones reales, una por carga, sin acelerar las pruebas. Omitimos la preparación técnica entre ambas sesiones y la espera posterior a la demostración. Conservamos completas las dos ejecuciones, sin aceleración.

Duración: 3 min 48 s. Resolución: 1518 x 914. Formato: MP4 / H.264. Pistas de audio: ninguna.

- 00:00: plan y carga de 100 usuarios; revisión de la aserción.
- 01:43: carga de 300 usuarios; respuesta del carrito y resumen final.
